# バクソ配信監視ツール (BKS-Surveillance)

Kickの特定チャンネル（tsubanyan）を監視し、規約違反行為の証拠を効率的に記録・通報するための非公式Webツールです。
GitHub Pages でホスティングされており、誰でもブラウザからアクセスして利用できます。

**公開URL:** https://bksdx.github.io/BKS-Surveillance/

---

## 主な機能

### 1. リアルタイム監視
* Kickの配信画面を埋め込みプレイヤーで表示します。
* ブラウザの自動再生ポリシーに対応するため、初期状態はミュートです。「音声を有効にする」ボタンで音声を切り替えられます。

### 2. 証拠録画・スクリーンショット
* **高画質な録画:** 画面全体のキャプチャではなく、KickのHLSストリームから直接録画するため、ツールのスクロール操作などが録画に映り込みません。
* **タイムスタンプの自動計算:** 配信開始時刻とHLSの再生位置から「実際の配信とのギャップ（遅延）」を自動計算します。
* **録画終了時刻の表示:** 録画中は「今停止したら何時までの映像が保存されるか」をリアルタイムで表示します。
* **録画経過時間:** 録画が終了しても経過時間がリセットされないため、何分録画したかを正確に記録できます。

### 3. クイックメモ
* Kickのゼロトレランス（即時永久停止）項目を含む、規約違反の種別をワンタップで記録します。
* 自動でローカル時刻（ISO形式）が付与され、録画メタデータやZIPファイルに含まれます。
* 履歴はブラウザのローカルストレージに保存されるため、誤ってリロードしても消えません（クリアボタンで削除可能）。

### 4. 通報支援
* **通報情報をコピー:** 監視対象名、録画開始時刻、タイムスタンプ、VOD/クリップURL、クイックメモ履歴をまとめたテキストをクリップボードにコピーします。そのままKickのサポート窓口（support@kick.com）に送信できます。
* **証拠ZIPを生成:** 録画したWebMファイルとメタデータ（テキスト）を1つのZIPファイルにまとめてダウンロードします。
* **クリップURLの記録:** Kick上で手動生成したクリップのURLを入力・保存できます。

## ⚠️ 重要な注意事項（必読）

本ツールを利用する前に、以下のルールを必ず守ってください。

1. **Kickアカウントにはログインしない**
   * ログインした状態で配信を開くと「アクティブな視聴者」としてカウントされ、配信者の実績（時給算定）に影響を与えてしまいます。
   * **必ずシークレットモード（プライベートブラウズ）**を使用するか、**Kickにログインしていない別ブラウザ**を使用してください。
2. **チャット欄は開かない**
   * チャットの接続や閲覧は相手のエンゲージメント（会話の活性度）を上げてしまうため、**動画プレイヤー部分のみ**を確認してください。
3. **通報は別ブラウザから行う**
   * 証拠を確保した後、通報手続き自体はご自身のKickアカウント（ログイン済みのブラウザ）または公式フォームから行ってください。
4. **録画の利用範囲**
   * 録画・スクリーンショット・クリップは**通報目的の私的利用に限定**してください。無断でのSNS公開や再配布は、Kickの利用規約違反や著作権侵害に該当する可能性があります。

## 使い方

### ステップ1: ページを開く
https://bksdx.github.io/BKS-Surveillance/ にアクセスします。プレイヤーが表示され、配信が始まっていれば映像が流れます（初期状態はミュート）。

### ステップ2: 必要に応じて音声を確認
配信の音声を確認したい場合は「音声を有効にする」ボタンを押します。もう一度押すとミュートに戻ります。

### ステップ3: 問題発言・行為の記録
1. 問題が発生した瞬間に「**証拠録画を開始**」ボタンを押します。
2. 録画中に「クイックメモ」を押すと、発生時刻と違反種別が自動記録されます。
3. 必要に応じて「**スクリーンショット**」ボタンで静止画も保存します。
4. 問題箇所が終わったら「**録画を停止・保存**」ボタンを押します。

### ステップ4: 証拠の整理
1. Kick上で該当箇所のクリップを作成し、URLを「クリップURL」欄に貼り付けます（任意）。
2. 「**通報情報をコピー**」ボタンを押すと、通報用テキストがクリップボードにコピーされます。
3. 必要に応じて「**証拠ZIPを生成**」ボタンを押し、録画ファイルとメタデータをまとめて保存します。

### ステップ5: 運営への通報
確保した証拠（ZIPファイル、スクリーンショット等）と、コピーした通報用テキストを添えて、Kickのサポート窓口（`support@kick.com`）または公式の通報フォームから報告します。

## 技術構成

本ツールは以下の技術で構成されています。

* **フロントエンド:** HTML / CSS / JavaScript (GitHub Pages)
* **バックエンド (プロキシ):** Cloudflare Workers
  * KickのCORS制限を回避し、HLSストリームの取得とAPI通信を行うためのプロキシです。
* **データ取得:** Kick API (非公式エンドポイント), HLS.js
* **ファイル処理:** JSZip

### 開発者向け情報
* コード内の `const PROXY_BASE = 'https://kick-proxy.bakusodx.workers.dev';` をご自身のCloudflare WorkersのURLに変更することで、ご自身の環境でも動作します。
* スマートフォンのブラウザでは、セキュリティ制限（MediaRecorderの非対応など）により録画・スクショ機能は動作しません。スマホの場合は端末標準の画面録画機能をご利用ください。
